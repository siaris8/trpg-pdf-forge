# 版式系统：纸本档案 / Paper Archive

这套版式参考了用户提供的样书气质：奶油纸、黑墨、金线、红色菱形、深色规则条、可扫读的表格。参考样书本身只作为版式语言；不复制其正文、插图或字体文件。

## 1. 页面

- A4 纵向：210 × 297 mm；正文内容区约 174 × 259 mm。
- 页边距：上 18 mm，左右 18 mm，下 20 mm。
- 正文默认双栏，栏间距 8 mm；表格、整页图、章节扉页跨双栏。
- 每页内容密度目标 60–75%；章节扉页可以更低，但不要整页只有标题。
- 封面单独渲染，满版，无页眉页脚；正文页眉页脚由渲染器添加。

## 2. 色板

| Token | 色值 | 用途 |

## 3. 字体

- 正文：`"SimSun", "Songti SC", "Source Han Serif SC", serif`。
- 标题：`"Microsoft YaHei", "PingFang SC", "Source Han Sans SC", sans-serif`。
- 拉丁眉题/数字：`"Arial Narrow", "Arial", sans-serif`，大写，字距 `0.12em`。
- 正文 9.5–10 pt，行高 1.65；表格 8.5–9.5 pt；图注 8 pt。
- 中文标题 28–36 pt，节标题 18–22 pt，小节 12–14 pt。
- 不使用变量字体；不使用 Type3。

## 4. 页眉页脚

- 页眉左：书名/章节；右：英文眉题或页码。
- 页脚左：`THE HOUSE EDGE` 式的小型书名；右：页码。
- 字号 7–7.5 pt，颜色 `--muted`；不与正文抢视线。
- 封面不显示页眉页脚。

## 4.1 PDF 书签

- 全篇 PDF 必须有层级书签；不要求正文超链接。
- `h1` 作为章（1 级），`h2` 作为节（2 级）；`h3` 只有加 `data-bookmark` 时才作为 3 级。
- 角色卡/数据块/卡片里的标题不加书签；要加就显式 `data-bookmark` / `data-bookmark-level`。
- 封面自动加「封面」书签；正文页码由封面页数偏移，不手填。
- WPS/Adobe 通过 PDF outline 显示；设置 `/PageMode /UseOutlines`。
- 书签页码必须等于 PDF 物理页；正文页数 ≠ `.page` section 数时先修分页。
- 详见 `.trpg/BOOKMARKS.md`。

## 5. 组件

### 章节扉页 `.section-opener`

- 大号中文标题 + 英文全大写眉题 + 一条金线。
- 可选一张满版或半版插图；没有图就用大号数字/菱形/留白。
- 不要放大段正文。

### 朗读框 `.read`

- 浅纸底 `--paper-light`，左侧 2.5–3 mm 金色边线。
- 8.8–9.2 pt 斜体（中文可用正常体 + 轻微字距），行高 1.7。
- 标签 `READ` 小号全大写，金色。

### 规则条 `.rule`

- 深色 `--ink` 或 `--navy` 底，白字；标签 `RULE` 金色。
- 只放一条可执行规则，不超过 5 行；长规则拆成正文 + 规则条。
- 不要在一页堆三条以上。

### 表格 `.table`

- 表头深色底、纸色字；隔行米色；无竖线或极细竖线。
- 表题在表上方，小号全大写 + 中文说明。
- 数字右对齐，骰式居中，文本左对齐。
- 表头重复；跨页拆表时使用“（续）”。
- 表格不能窄于正文栏的 80%，也不能低于 8.5 pt。
- **表格优先**：人物卡、武器/护甲/装备、法术/能力、弹药、战利品、随机表、房间钥匙，只要字段可横向比较，就先用表格。
- 字段规格：武器 5–6 列（名称/伤害/射程/弹药/特性/重量）；法术 6 列（名称/环阶或消耗/时间/射程/成分·持续/效果）；角色属性 3–4 列。
- 不把整段规则塞进单元格；单元格超过 3 行就移出表格。

### 角色卡 `.character-sheet`

- 纸白底、细边；顶部身份条（姓名/职阶/等级/玩家/所属）。
- 下面四块：属性表、衍生值、武器表、法术/特质表。
- 一页一张角色卡；不要把所有字段做成一整张巨表。
- 原卡是手绘/可填写/特殊版式时，做**抽象表 + 原图**；原图放 `out/SOURCE-CARDS/` 和附录，不能只留其一。

### 原卡附录 `.source-card`

- 原卡图放在附录页；图注写原页码、角色名、“原卡仅供核对，抽象表见 p.X”。
- 宽卡/横排扫描用 `class="source-card landscape"`。
- 原卡图是核对材料，不算正文装饰插图；整页扫描可以进附录，但不要压在正文下。

### 便签 `.note`

- 浅金底 `--gold-soft`，细边，左上角小标签 `NOTE`。
- 用于裁判提示、变体、译注；不超过 6 行。
- 不要用便签承载核心规则。

### 数据块 `.statblock`

- 深色 `--navy` 底，纸色字；名称大号，属性两列网格。
- 用于 NPC/怪物/守卫；数值必须与原文一致。
- 一页最多两个数据块。

### NPC/房间卡 `.card`

- 纸白底、细边、顶部小标签；头像可选。
- 字段用定义列表，不要塞成大段。
- 一页最多三个卡。

### 图 `.figure`

- 图宽 100%，最大高度 90 mm；图注 8 pt。
- 整页图只用于章节扉页；不要在正文页放半张模糊图。
- 图内文字无法替换时，用图注说明，不硬改。
- **源 PDF 有可用插图时，不要 0 图。** 首轮预览/难页至少 1 张；全篇至少 3 张关键图（源书可用图不足 3 张时保留全部可用图）；长书建议每 4–6 页一张视觉锚点。
- **源书没有可用插图时，0 图允许。** 只有图标、花纹、整页扫描或全部不可校对时，不要硬塞；在报告里说明即可。
- 优先使用 `hero`（章扉页/关键场景）、`scene`（地图/房间/NPC/道具）；`icon` 不必逐张嵌入，可改为 CSS/内联 SVG。
- 同一张图不要反复填空；不要用整页图压住正文。图必须实际出现在 HTML/PDF 里，只提取到 `work/images/` 不算。
- 图片必须来自用户源 PDF 或 `assets/user/`；不要使用参考书插图。

### 拉引 `.pullquote`

- 大号 14–18 pt，左侧金色线；只放一句有气氛的原文/译文。
- 不替代规则文本。

## 6. 节奏

- 每 2–3 页至少有一个视觉锚点：表格、便签、图、数据块、章扉页。
- 连续正文不超过 5 行；用小节标题、列表、提示框切开。
- 一页不要同时出现超过 3 个同权重的大元素；难页优先“分栏 + 分区”，不要把所有东西堆在顶部。
- 留白是设计的一部分：表格之间至少 4 mm，组件之间 5–6 mm。

### 6.1 页面填充（提示，不阻断）

- 目标 65%–85%；低于 55% 优先把下一页开头的正文/表格前移，或合并相邻页；不要为填满而编造内容。
- 正常留白不算问题：章节扉页、表格/图前后的避让、章节末页、术语表/索引、后记/版权页。
- 只有“整页只排一半”“整栏空着”“页底空 ≥120mm 且没有表格/图/章节理由”才值得处理。
- 栏数按**译文体量**选，不按源书栏数硬套：正文默认 2 栏；密表/索引可 3 栏；大图/叙事可单栏。源书 3 栏不代表输出必须 3 栏。
- 稀疏页显式写 `data-layout="sparse"`；章节扉页用 `.section-opener`。`layout-check.py` 会把它们标为 `exempt` / `context`。
- `out/pass1/LAYOUT.json` / `out/LAYOUT.json` 只是体检报告：`strong` 建议处理，`mild` 可接受，不阻断审核。

### 6.2 分页

- 按译文体量分页，**不要一源页 = 一输出页**。
- 合并顺序：下一页开头的正文/便签前移 → 合并整页 → 最后才换栏数。
- 单栏页目标 ≥70%；双栏页两栏底边差 ≤70mm（表格/图造成的差异除外）。
- 章节扉页每章最多一个；不要用扉页填空。

## 7. 难页处理顺序

1. 先按语义分区：规则、表格、图、侧栏、数据块。
2. 能拆的表格拆开，重复表头；不能拆的切横排页。
3. 图放不下就缩到 90 mm 高或改成图注 + 表格。
4. 侧栏内容如果超过 8 行，改成正文小节或便签。
5. 最后才调字号；8.5 pt 是表格下限，9.5 pt 是正文下限。

## 8. HTML 结构

```html
<section class="page">
  <div class="page-head">
    <span class="eyebrow">THE CLOCK ROOM</span>
    <h1>钟表室</h1>
    <p class="dek">一句导语。</p>
  </div>
  <div class="columns">
    <div class="col">
      <p>正文……</p>
      <aside class="read"><span class="label">READ</span><p>朗读文本……</p></aside>
    </div>
    <div class="col">
      <div class="rule"><span class="label">RULE</span><p>规则……</p></div>
      <table class="table">……</table>
    </div>
  </div>
</section>
```

- 每页一个 `.page`；全篇按页生成，避免浏览器自动分页不可控。
- 表格、图、数据块使用 `.span-2` 跨栏。
- 不在 HTML 里写页眉页脚；渲染器负责。
- 封面使用 `.cover`，单独 HTML，`@page { margin: 0; }`。

## 9. 字体与渲染

- 由 `.trpg/render-pdf.mjs` 调用 Chrome/Edge 打印。
- 正文页眉页脚由 CDP 的 `headerTemplate` / `footerTemplate` 生成。
- 封面 `--no-header` 单独渲染，再由 `.trpg/merge-pdf.py` 合并。
- 渲染后必须运行 `.trpg/check-pdf.py`，0 Type3 才算通过。
- **SVG 内不要写 `<text>`**：Chrome 会把 SVG 文字输出为 Type3。图标只用路径；文字标签用 HTML 叠加。
- 含中文的标签使用 `var(--sans)`，不要用纯拉丁字体栈，否则逐字回退会生成 Type3。

## 德语源补充

- 德语 `ä ö ü ß` 使用拉丁字体回退，不要转成 `ae/oe/ue/ss`；仍然要求 0 Type3、字体全部嵌入。
- 德语长复合词按语义翻译；中文断行不要基于德语原词长度硬切。
- 德语引号 `„ “ ‚ ‘` 只用于原文对照；中文正文使用中文引号。
- 数字、骰式、价格保留源书格式，不按中文习惯改写。

## 波兰语源补充

- 波兰语 `ą ć ę ł ń ó ś ź ż` 使用拉丁字体回退，不转写；仍要求 0 Type3、字体全部嵌入。
- 波兰语引号 `„ ”` 只用于原文对照；中文正文使用中文引号。
- 数字、骰式、价格保留源书格式。
